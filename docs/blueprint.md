# **App Name**: Rivers Connect

## Core Features:

- Landing Page Showcase: A clear and engaging landing page showcasing Rivers Software House's expertise in AI, Website development, RPA, and Web Scraping.
- Lead Capture Form: A lead capture form to collect visitor contact information (e.g., phone number, email) and consent for future communications.
- Project Portfolio: A portfolio section displaying past projects with an easy content management system (CMS) to add and update examples. Consider using Markdown files to store the content.

## Style Guidelines:

- Primary color: Deep blue (#003366) to convey trust and professionalism.
- Secondary color: Light gray (#F0F0F0) for a clean and modern background.
- Accent: Teal (#008080) to highlight key elements like buttons and calls to action.
- Clean and modern typography for easy readability.
- Professional and relevant icons to represent each service (AI, Web development, RPA, Web Scraping).
- A clear and intuitive layout with a hero section, services overview, project portfolio, and contact form.
- Subtle animations for a smooth and engaging user experience.
